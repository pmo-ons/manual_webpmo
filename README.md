# Guia do Usuário do WebPMO — pacote para Power Pages

Este pacote contém um protótipo navegável e os artefatos-base para implantação no Microsoft Power Pages.

## Visualização local
Abra `index.html` em um navegador. Para pesquisa e navegação completa, recomenda-se servir a pasta por um servidor HTTP local.

## Arquivos
- `index.html`: página completa do guia.
- `styles.css`: identidade visual e responsividade.
- `app.js`: sumário, menu móvel e pesquisa local.
- `assets/`: imagens extraídas do Word.
- `power-pages-web-template.html`: base para Web Template.
- `DEPLOY_POWER_PAGES.md`: roteiro de implantação.
- `PENDENCIAS_EDITORIAIS.md`: itens a revisar antes da publicação.

## Domínio recomendado
Preferencial: `guia.webpmo.ons.org.br`
Alternativo: `guia.webpmo.ons.com.br`
